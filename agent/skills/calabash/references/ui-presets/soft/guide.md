# 柔和彩色 / Soft

Use the bundled tokens from frontend/calabash-theme.css. Use var(--calabash-primary), var(--calabash-gap), var(--calabash-radius) and semantic colors rather than hardcoding another theme. Keep Ant Design and shared Calabash components.

Use soft accents, subtle card grouping and generous but bounded spacing. Keep text contrast, data legibility and compact action bars. Avoid decorative gradients, excessive shadows and oversized empty dashboards.

Preserve user-requested layout and business behavior. Design tokens are a foundation, not a fixed page template. No external fonts, scripts or network assets.
