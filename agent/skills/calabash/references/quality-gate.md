# 交付检查

检查目录格式、Python 语法、React/TypeScript 编译与接口契约。先确认主流程，再检查空状态、错误、重复提交、安全取消和文件结果。界面修改保留已有功能与数据。

静态校验不执行源码；构建成功不等于运行通过。预览交互必须用户授权并逐次确认；修复后手动重试。正式保存构建成功后才原子切换，失败保持原版本。

交付后用 check_tool_build 获取当前源码版本的严格类型检查和生产构建结果，按诊断位置修复并重查。预览页显示检查中、通过或失败；保存复用该版本的构建产物，版本变化或产物不可用时重新检查。不要把 Vite 页面能显示当作构建通过，不用跳过类型检查来换取保存成功。
