# 办公工具 UI 规范

使用 Element Plus 的成熟交互组件，按照工具绑定的 UI 预设组织外观，不固定 Fluent 2。创建前用 read_ui_preset 获取所选预设；修改已有工具先读 tool.json 的 ui 与现有主题快照。页面应围绕用户工作目标设计，不统一套用管理后台模板。

- 使用预设提供的颜色、圆角与间距变量；强调色不固定为蓝色。语义上的成功、警告、错误仍须清楚且可读。工具预设是设计基础，不是固定页面模板。
- 间距采用 4/8/12/16/24/32，正文 14px，标题 22–28px。表单标签清楚，操作区紧邻对应内容。主操作突出，危险操作单独确认。
- 小工具用清楚的单页布局；复杂工具可用局部侧栏、分区或标签。根据内容选择，不为每个工具添加无用的导航和统计卡片。
- 表格提供合理列宽、溢出处理、空状态与筛选。容器 min-width:0；窄屏调整布局，避免整个页面横向滚动。
- 输入、校验、加载、失败、完成、取消均有可见反馈。图标使用统一的 @element-plus/icons-vue 线性风格，图标按钮有 aria-label 与提示。
- 文件列表可以追加、移除和清空，执行中冻结。结果文件为空时不占空间，有结果时紧凑呈现。任务显示真实进度，不以动画冒充完成。
- 不复制 App 外壳样式到工具，不让工具 CSS 覆盖宿主。优先 Element Plus 属性与 CSS 类；组件样式 scoped。
