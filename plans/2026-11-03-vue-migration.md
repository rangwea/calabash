# Vue 工具与桌面 UI 迁移方案

状态：已按确认范围实现迁移；自动回归、macOS arm64 打包及合成数据原生交互验收通过。

## 目标与现状

Calabash 面向可通过对话创建、反复使用的本地办公应用。统一采用 Vue 3、TypeScript、Element Plus、Vite 和 FastAPI，最终移除 NiceGUI、Quasar 及其专用协议、模板、打包配置和测试。

迁移前宿主与工具均通过 NiceGUI 创建界面。当前 `desktop-ui/src/` 实现 Vue 工作区，`api/` 提供 FastAPI 接口，`service/tools/tool_workers.py` 按需启动隔离工具进程；旧页面、组件和 NiceGUI 运行依赖已移除。

保留 Tauri 壳、macOS Overlay、Python 业务服务、SQLite、Deep Agents、能力插件签名与本地 ZIP 导入边界。不引入登录、远程服务、Docker、任意 Shell 或子 Agent。

## 技术选择

采用完整切换，按可验证的纵向流程实施。迁移中可以暂存旧实现，但最终依赖和可执行路径不得包含 NiceGUI。不长期维护两套 UI，也不把现有 `.py` UI 伪装成 Vue 工具。

App 与工具使用相同基础组件库，但各自限定主题和状态作用域。现有 Fluent 2 办公风格通过共享设计变量延续，不宣称 Element Plus 是官方 Fluent 实现。

## 桌面前端

Vue 实现侧栏、聊天、图片输入、活动步骤、预览、工具列表、多标签、设置、确认对话框、结果与任务组件。保留侧栏收缩与拖动、多对话并行、工具切换状态、离开提醒和中英文。

前端调用 FastAPI 明确的查询、命令和事件接口。聊天生成在后端持有任务；切换页面不取消生成。SSE 事件具有递增序号，重连先读取当前快照，再续接事件；取消是独立命令，关闭页面与取消任务分开处理。

生产 App 加载构建后的静态文件，不依赖 Vite 开发服务启动。保留 Tauri 启动就绪通知和原生文件桥接。

## 工具目录与交付

工具以 `~/.calabash/tools/<project>/<name>/` 为单位，包含：

```text
tool.json             # 身份、入口、声明的能力和受支持依赖
frontend/App.vue      # 小工具可以只有此组件
frontend/components/ # 按需要拆分，不强制创建空层
backend/main.py       # 注册受控路由，不自行启动服务器
backend/services/    # 可选业务模块
dist/                 # 保存正式版本时生成的静态产物
```

宿主管理前端依赖和构建配置；工具不得自带安装脚本或要求用户安装 Node、Python、uv。Node 与前端构建资源的跨平台分发、离线运行、许可证及打包体积须在首个纵向原型中验证，不能仅在开发机上依赖系统 Node。

预览采用草稿快照和 Vite 按需服务；Agent 保存修改后由用户手动刷新，重新加载对应快照与后端实例，不承诺刷新后业务内存状态保留。Vite 的模块热更新不会绕过此手动重试边界。正式保存针对整个版本快照构建，成功后原子切换；构建失败保留旧正式版本。依赖缺失明确报错，不在导入或运行时静默联网安装。

工具索引仅识别当前 Vue 目录格式，不再识别旧 `.py` 工具，也不提供转换入口或兼容运行时。用户自行清理本机测试工具，应用不自动删除用户文件。

## 运行与安全边界

宿主和工具使用隔离的浏览器来源及会话令牌，不向工具页面暴露宿主凭据或 Tauri 高权限桥接。仅绑定 `127.0.0.1`；校验 Origin、Host 与请求令牌，禁止通配 CORS。令牌不得进日志或 Agent 状态。

工具后端使用独立进程，按打开工具惰性启动；前端预览服务按需启动，不在 App 启动时恢复运行所有工具。工具卡死不应阻塞宿主聊天、设置和其他工具。隔离进程用于故障边界，不宣称是执行不可信代码的安全沙箱。

文件 SDK 使用宿主授权的文件引用；结果通过结果服务交付，不开放任意路径读取。Python 依赖使用内置库或已确认的能力插件。ZIP 校验覆盖路径穿越、符号链接、解压大小、同名覆盖和运行中覆盖；导入不执行代码和依赖脚本。

## Agent 与验收

草稿、修复授权、精准代码检索、局部补丁和 revision 校验扩展到工具目录；路径限定当前工具，不允许跨目录操作。日志与错误包含文件位置、后端调用栈和前端诊断，沿用运行隔离及清理规则。

更新内置 Skill、模板和 API 查询，使 Agent 创建 Vue 工具并查询固定版本的组件接口；清除 NiceGUI 接口建议。保存修改、构建成功、渲染通过和业务检查通过分别记录。

预览检查延续当前会话与源码版本绑定。诊断需授权，点击和输入逐次确认；真实写入、删除和导出另行明确确认。修改与刷新后重新授权。DOM 和媒体状态检查不等于截图、听觉或完整业务验收。

## 实施顺序与验收门槛

1. 建立 Vue 宿主、FastAPI 会话及事件接口，打通聊天到合成 Vue 工具预览。验证离线构建资源和跨平台运行方式。
2. 完成目录工具的读写、版本、预览、构建、发布、索引及 ZIP 导入导出；接入 Agent 精准修改和诊断验收。
3. 迁移所有现有用户入口：工具多标签与状态、文件与结果、任务取消、能力插件、模型与图片设置、修复和确认流程。
4. 删除 NiceGUI 页面、组件、专用服务与依赖，更新锁文件、构建、文档和 AGENTS；替换相应测试，不能以删除测试代替能力迁移。
5. 合成数据验证创建→预览→修改→确认操作→验收→正式保存→重复使用→ZIP 分享；确认旧正式版本和用户文件不被覆盖。
6. 执行 Python、前端类型与组件、浏览器端到端、Rust、生产打包与真实安装包验收。检查源码可执行路径、依赖树和冻结产物均无 NiceGUI。

完成标准是以上流程和已有能力通过，不是新首页可见或前端构建成功。迁移提交按纵向切片保持可审查；未经要求不提交、推送或替换用户已安装 App。

### 原生验收补充修正

- Tauri 本地启动页等待后端导航，不提前请求 HTTP API，避免短暂显示 URL 格式错误。
- 工具 SDK 从当前运行环境判断原生文件交付能力，不再将构建机器的环境固化到工具产物；补充 SDK 回归。
- macOS 默认菜单 Quit 的原生 terminate 动作绕过 ExitRequested；替换为自定义菜单事件并调用 AppHandle.exit，使菜单和 Cmd+Q 进入安全退出流程，其他原生菜单保留。
- 增加多个工具进程任务计数聚合测试。原生运行记录确认 active=1 时发起停止，当前项目完成后 active=0 才退出；合成批次的其余项目未执行。

### 生成失败回归修正

不可用目录原先以 Invalid tool files 抛出，工具异常未返回给模型，导致整轮生成终止，并被 UI 泛化为模型连接问题。现对不存在的工具统一返回 tool_not_found，对有界的参数、文件、权限和语法错误返回结构化 ToolMessage；未知程序异常仍终止并写入本机日志。合成模型回归覆盖先触发旧行为失败，再从同一检查点继续并创建 Vue 草稿，无真实模型额度。
