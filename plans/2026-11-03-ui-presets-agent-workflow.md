# UI 预设和 Agent 工作流第一阶段

范围：配置默认工具 UI、创建时 @ 选择、主题版本快照；单 Agent 的阶段、交接资料与未来角色工具权限基础。没有启用子 Agent、多模型流水线、Shell 或外部 tracing。

预设源位于内置 Skill 的 references/ui-presets，包含元数据、CSS tokens、规则与 Vue 示例。当前内置 office / compact / soft，不固定 Fluent 2。仅加载所选包的资料。

选择优先级：当前用户消息的 @ 指定 > 当前工具的 ui 与 CSS 快照 > 新工具的全局默认。普通编辑不覆盖主题快照；自定义变化使用 scoped 样式。已有未绑定预设的工具也保持原样，除非明确 @ 换风格。导入导出携带主题元数据和 CSS，不依赖另一台机器的默认设置。本阶段不提供第三方 UI 包安装或在线下载。

Agent 阶段随实际工具调用记录，不增加额外模型调用：需求分析、编写或修复、验证、交给用户试用。复杂任务可记录短需求摘要、保留约束与验收条件；简单编辑不强制规划。交接文件在本机 agent/task_contexts，删除会话时同步清理，不记录模型连接信息，凭据经已有脱敏服务处理。

分析角色只读源码和参考资料，可整理需求；验证角色只读源码，可进行确定性构建检查和经过现有授权流程的页面验收，不修改源码或需求。编写和修复只写当前会话草稿；正式发布仍由用户确认。当前对话并发锁、操作回执和 revision 校验继续负责单写者及冲突保护。

后续阶段：基于固定办公任务比较成功率、成功任务成本和耗时，再决定独立 Agent 的调度策略；不默认让每个任务经过所有角色。
