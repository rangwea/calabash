这份指南帮助你从模型配置开始，创建、试用和复用本地工具。
不需要 Calabash 账号；创建和修改工具需要你自己的外部模型连接。

01 / START HERE

开始之前

Calabash 是本地桌面应用，不是浏览器里的远程管理系统。工具和结果保存在本机，AI 负责根据你的描述生成和编辑工具代码。

v1.3.1 预览版已发布。前往 GitHub Releases 下载，选择 macOS arm64、macOS x64 或 Windows x64 安装包。开发者分发签名与 Apple 公证尚未完成，不要为安装而关闭系统安全保护。

  1. macOS：打开对应架构的 DMG，将 Calabash.app 拖入“应用程序”；Windows：运行 x64 安装程序。
  2. 等待启动完成，进入工具桌面。最终用户不需要另行安装 Python、uv 或 npm。
  3. 打开侧栏“设置”，配置模型连接；然后从左侧“新会话”开始。

02 / CONNECT A MODEL

选择你自己的模型

目前支持 DeepSeek、OpenAI、Anthropic 和通义千问的外部模型接口。你需要相应服务商的 API Key；Calabash 不提供共享密钥或免费模型额度。

  1. 在设置中的模型配置区域选择服务商，填写 API 地址和自己的 API Key。
  2. 获取模型列表，选择该连接实际可用的模型，再保存配置。
  3. 回到对话框，在底部的模型选择器中切换模型。模型版本以接口返回的可用列表为准。

模型可用性、接口地域、限额和费用由服务商决定。连接失败时，请先检查密钥、地址、账户额度及模型 ID；不要把 API Key 粘贴到普通对话里。

03 / BUILD YOUR FIRST TOOL

从一个具体需求开始

比起“做一个万能系统”，先说清楚输入、规则、界面和结果。下面的描述可以作为起点：

“创建一个 Excel 统计工具。选择销售工作簿，按地区或产品汇总销售额，展示明细和柱状图，最后导出汇总 Excel。不要覆盖原始文件。”

  1. 点击“新对话”，选择模型并描述需求；需要时添加合成或已脱敏的示例文件。
  2. 工具生成后，在右侧打开预览。亲自试用字段、筛选和导出，检查结果是否符合预期。
  3. 继续提出修改，例如“增加月份筛选”或“把失败项单独列出来”。静态检查通过不等于工具已经运行验证。
  4. 以后可从工具列表直接运行，或点击工具旁的对话入口，引用该工具继续修改。

官网的五个场景使用真实工具界面与合成数据录制，是可创建的示例，不是固定内置业务模块。

04 / WORK WITH FILES

文件输入与批量任务

在工具内选择文件，可以追加、移除或清空当前选择。执行前检查文件可用状态；如果文件被移动、修改或权限失效，请重新选择，而不是继续使用失效引用。

  • 目录权限：遇到“Operation not permitted”时，重新通过系统选择器选择文件或目录，并在设置中检查目录访问状态。
  • 执行中：采用平台组件的工具会锁定输入，防止重复提交；界面展示实际进度、成功和失败状态。
  • 取消：采用安全停止方式。正在处理的文件完成后，再停止后续任务；不是立刻强杀正在写文件的线程。
  • 失败重试：使用工具提供的失败项重试入口，避免重新处理已成功的文件。任务进度不会跨 App 重启恢复。

05 / KEEP THE RESULTS

结果是文件，不只是一段回复

使用平台结果组件的工具会把导出文件写入独立输出目录，并保存结果历史。完成后可以打开文件、定位目录或保存副本；刷新、重新打开或重启后仍可查看已登记的结果。

如果产物被移动、删除或修改，结果会显示不可用。导出应创建新文件，不覆盖输入。删除工具会保留历史对话、结果和日志，但会永久移除工具源码。

06 / SHARE A TOOL

用 ZIP 导入和导出工具

  1. 在工具列表点击工具旁的导出图标，将单个工具保存为 ZIP。分享前检查源码中是否硬编码了密钥或业务数据。
  2. 点击列表顶部“导入工具”，选择 Calabash 格式的本地 ZIP，核对工具名称、项目和说明后再确认。
  3. 同名工具默认不会被覆盖。可以更换工具标识，或明确勾选覆盖；运行中的工具不允许覆盖。
格式与边界说明
ZIP 内容manifest.json + tool.py
大小限制ZIP 最大 2 MB，源码最大 1 MB
不包含聊天、结果文件、日志和应用配置
导入来源仅本地 ZIP，不支持 GitHub 地址

导入不会执行代码或安装依赖。格式和语法检查不是安全沙箱；第三方工具运行时可以执行本地代码，请只导入可信来源。

07 / OPTIONAL CAPABILITIES

能力插件与工具不是一回事

常见表格、文档和图片处理库随 App 内置。FFmpeg 是单独的本地能力插件，用于支持相应的音视频处理工具，不随主 App 打包，也不会自动下载。

  1. 获得可信发布者提供、适配当前系统的签名能力插件 ZIP。
  2. 在设置的“能力插件”区域导入，等待安全校验和自检完成。
  3. 回到工具手动重试。不要把能力插件 ZIP 导入工具列表，也不要把工具 ZIP 当作能力插件。

当前 FFmpeg 插件面向 macOS arm64；媒体适配器提供探测、音频提取以及有限格式转换，不代表支持所有 FFmpeg 编码器。OCR、自动转写、字幕生成和 Office 转 PDF 引擎尚未提供。

08 / DATA & TRUST

“本地运行”的边界

工具源码位于 ~/.calabash/tools，本地索引、对话及结果元数据保存在本机。应用不提供文件云盘、远程管理后台或 Calabash 账号。

外部模型并不在本机运行。你的对话，以及 Agent 读取后纳入请求的相关文件内容，可能发送至所选服务商。附件建立本地引用不等于文件正文已经发送，但后续读取仍需要留意数据边界。

先用合成或脱敏数据测试工具。不要让 Agent 无意读取密钥，不要导入不可信代码，也不要把本地模型配置文件或业务附件放进分享包。

09 / TROUBLESHOOTING

遇到问题时

模型连接失败

检查网络、API 地址、密钥、服务地域、模型可用性及账户额度。重新获取可用模型后再选择。不要把完整密钥发送给他人排查。

文件无法读取或权限失效

通过系统选择器重新选择文件，在设置中检查目录权限，并确认文件未被移动或修改。浏览器预览与桌面原生文件选择不是同一种环境。

生成的工具运行报错

可在确认后将必要错误摘要交给 Agent 修复。默认不发送文件正文、密钥或完整日志；修复完成后由你手动重试，不会自动重跑有副作用的任务。

ZIP 导入失败

确认它是 Calabash 工具 ZIP，而非普通项目压缩包或能力插件包。检查大小、格式与文件权限；发生同名冲突时改名或明确确认覆盖，勿覆盖运行中的工具。
